The question: more robots, or complementary capabilities?

The task is to move scattered particles into a target receptacle in an enclosed environment. A pushing robot can collect objects through local contact; a blower can influence objects over a larger area. I investigated whether these different capabilities could divide the work usefully.

The study grew from Learning Pneumatic Non-Prehensile Manipulation with a Mobile Blower and Spatial Action Maps. Those research methods provide the reference setting and action representation. My course project adapted the simulation to test heterogeneous combinations, fixed blower placements, and interference among agents.

Reference mobile-blower project

From a spatial map to a shared physical outcome

Spatial Action Maps express possible action endpoints in the same spatial domain as the scene representation. The course experiments combined that representation with single-frequency Deep Q-Learning. The earlier mobile-blower paper’s multi-frequency method is discussed as related work, separate from the simpler learner used in this study.

The key experimental change was to assign different physical effects to agents and inspect how their actions alter one another’s environment. A fixed blower can gather particles into a smaller region; a mobile pusher can then move the local cluster toward the receptacle.

Experimental conditions

The report studies small empty, large empty, and large-column environments. It varies the number of agents and the position of fixed blowers, including the top-center and several corners. The target occupies the top-right corner.

The recorded training budget is 80,000 steps per robot, so a three-robot setup uses 240,000 steps. Budget grows with agent count; this is important context when comparing configurations.

What worked, and what broke

The report records that a mobile blower and pusher worked better qualitatively than two mobile blowers in the tested setting. Two blowers could send particles back and forth, while the pusher offered more precise local collection. A well-positioned fixed blower also helped dislodge particles from walls.

Adding another fixed blower did not consistently help. In the reported two-blower-plus-pusher condition, close proximity and rapidly changing particle motion disrupted the pusher, which repeatedly acted on empty areas. The report proposes interference as an explanation; it does not establish that mechanism through a separate ablation.

These are qualitative observations from the course experiments. Exact path analysis and timed particle-count comparisons were listed as future work, so I do not attach a percentage improvement to them.

My contribution and the next question

I studied the reference methods, adapted the PyBullet environment for agents with different functions, ran the placement and composition experiments, and independently wrote the research report.

This project made capability-dependent representation tangible for me. A shared scene does not imply a shared action set, and helpful behavior must be judged by how it changes another agent’s task. My later work asks how an agent can identify the evidence that matters for its own next action.
