01 · The engineering question

What has to happen beneath a training loop?

A short model definition depends on a substantial stack: parameters must be found, tensor indices must reach the correct storage locations, operations must retain the history needed for gradients, and execution backends must preserve those rules.

This Cornell Tech course project let me implement those mechanisms inside an educational framework. I worked from scalar operations and tensor primitives through differentiation, compiled kernels, convolution, and an MNIST experiment.

def index_to_position(index, strides):
    position = 0
    for ind, strides in zip(index, strides):
        position += ind * strides
    return position

def backpropagate(final_variable_with_deriv):
    queue = [final_variable_with_deriv]
    while queue:
        cur = queue[0]
        var = cur.variable
        queue = queue[1:]
        if is_leaf(var):
            cur.variable._add_deriv(cur.deriv)
        else:
            for prev in var.history.backprop_step(cur.deriv):
                queue.append(prev)

def _map(out, out_shape, out_strides, out_size, in_storage, in_shape, in_strides):
    out_index = cuda.local.array(MAX_DIMS, numba.int32)
    in_index = cuda.local.array(MAX_DIMS, numba.int32)
    i = cuda.blockIdx.x * cuda.blockDim.x + cuda.threadIdx.x
    if i < out_size:
        count(i, out_shape, out_index)
        broadcast_index(out_index, out_shape, in_shape, in_index)
        o = index_to_position(out_index, out_strides)
        j = index_to_position(in_index, in_strides)
        out[o] = fn(in_storage[j])

05 · My contribution

Implement the missing operations, then connect the stack

The MiniTorch course supplied the framework, interfaces, task scaffolding, and tests. My work filled in implementations across parameter traversal, scalar and tensor operations, differentiation, CPU/GPU backends, convolution, and the MNIST classifier.

  • Representations: logical-index to storage conversion, broadcast-index projection, and tensor permutation.
  • Learning machinery: recursive module modes, named parameters, chain-rule logic, and derivative propagation.
  • Execution: tensor map/zip/reduce, matrix multiplication, Numba-compiled routines, and CUDA kernels.
  • Integration: convolution and neural-network functions, classifier construction, training-loop integration, and inspection through notebook and Visdom workflows.

Building across these layers made the connection between representation, numerical operations, execution cost, and learning behavior tangible. I carry that habit into robotics: when a system behaves unexpectedly, I want to inspect the component and assumption that produced the result.
